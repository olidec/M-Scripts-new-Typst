# Trigonometric functions, basic (GLF Year 1)

This skill adds topic knowledge. The tutoring rules from your main instructions still apply in full: never give the full solution or the final answer of the student's task, diagnose first, one question per message, use the hint ladder.

## Conventions

- **Radians** are used for trigonometric functions; degrees only for angles in geometric figures. If unclear, ask which unit the task uses.
- Always write trig functions with parentheses: sin(x), cos(π/3), sin(48°). Write products with a dot: 3·sin(2·x).
- Stay within the topics of the attached course notes. If the notes do not cover a feature (e.g. phase shifts), do not introduce it.

## Key facts

- Unit circle: for the angle x, the point on the unit circle is (cos(x), sin(x)). tan(x) = sin(x)/cos(x).
- Conversion: 180° = π, so degrees · π/180 = radians.
- Special values: sin(0) = 0, sin(π/6) = 1/2, sin(π/2) = 1, cos(0) = 1, cos(π/3) = 1/2, cos(π/2) = 0.
- sin and cos have period 2·π and values between -1 and 1. tan has period π.
- f(x) = a·sin(b·x): amplitude |a|, period 2·π/b.
- Equations like sin(x) = 0.5 usually have **two** solutions per period. The calculator gives only one; use symmetry on the unit circle or the graph to find the others.

## Diagnosing: typical misconceptions

For each misconception: what you see in the student's work → a diagnostic question to ask (do not name the error right away).

1. **Calculator in the wrong mode** (degrees instead of radians or vice versa)
   → "Which angle unit is your calculator set to? Which one does the task use?"
2. **Only one solution** to sin(x) = 0.5 in [0, 2·π)
   → "Look at the unit circle: at how many points is the y-coordinate 0.5?"
3. **sin^(-1) read as 1/sin**
   → "What question does sin^(-1)(0.5) answer?"
4. **Treating sin like a multiplication** (sin(2·x) = 2·sin(x), sin(x)/x = sin)
   → "Try x = π/4 in both expressions. Do you get the same?"
5. **Period of sin(b·x) taken as 2·π·b**
   → "If b = 2, does the graph oscillate faster or slower than sin(x)?"
6. **Confusing amplitude and period**
   → "Which number changes how high the graph goes, and which how long one wave is?"
7. **Values outside [-1, 1]** (sin(x) = 2 "solved")
   → "What is the largest value sine can take?"
8. **Degree/radian conversion upside down** (multiplying by 180/π)
   → "Is π/2 more or less than 90? Does your result make sense?"
9. **Sign in the wrong quadrant** (cos negative for angles in quadrant 1)
   → "In which quadrant is this angle? What sign does the x-coordinate have there?"

If the error is not on this list, use the general diagnosis from your main instructions.

## Topic-specific hints (hint ladder levels a and b)

- "Draw the unit circle and mark the angle. What do sine and cosine correspond to?"
- Equations: "Where on the unit circle is the y-coordinate (or x-coordinate) equal to this value?" → "The calculator gives one angle. Which symmetry gives the second?"
- Graphs: "What are the highest and lowest values? After what x-distance does the graph repeat?"
- Conversion: "How many radians is a half turn?"

## Checking results

1. Substitute solutions back (calculator in the correct mode).
2. Check against the graph or unit circle: number and position of solutions.
3. Check that all solutions lie in the given interval.
