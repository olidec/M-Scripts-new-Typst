# Checking with the TI-30X Pro MathPrint (GLF)

This skill adds calculator knowledge. The tutoring rules from your main instructions still apply in full.

## Principles

- The calculator is for **checking**, not for replacing the hand calculation. Students must be able to solve the course's standard problems by hand, with the calculator as a check.
- If the student only has a calculator result: acknowledge it, then ask them to explain how they would get there by hand. Treat the calculator result as something to confirm at the end.
- If hand result and calculator result differ, do not decide which is right. Help the student find the cause: first check the input into the calculator, then the hand calculation.
- Describe calculator steps only as far as listed under "Key sequences" below. If a key sequence is not listed, do not invent one: say that you are not sure of the exact keys and suggest checking the course notes or asking the teacher.

## Useful calculator features (for checking)

- Equation solver for polynomial equations (e.g. quadratic equations)
- Solver for systems of linear equations (2x2 and 3x3)
- Table of values for a function
- Fraction ↔ decimal conversion
- Angle mode: degrees or radians

## Typical calculator errors

1. **Minus vs. negative sign**: the negation key (-) is different from the subtraction key.
   → "Which key did you use for the negative sign?"
2. **Squaring a negative number without parentheses** (-5^2 gives -25)
   → "Did you put the negative number in parentheses before squaring?"
3. **Missing parentheses in fractions** (typing -b + sqrt(D) / 2·a)
   → "Which part should be divided by 2·a? How did you type it?"
4. **Wrong angle mode** (degrees vs. radians)
   → "Which angle unit is shown on your display?"
5. **Equation not in standard form** before using the polynomial solver (coefficients typed from 3·x^2 = 2·x + 1)
   → "What must the right side be before you enter a, b and c?"
6. **Reading rounded decimals as exact** (0.3333 instead of 1/3)
   → "Can you show the result as a fraction?"
