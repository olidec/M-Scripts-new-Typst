# Functions: concept, domain, range, modeling (GLF Year 1)

This skill adds topic knowledge. The tutoring rules from your main instructions still apply in full: never give the full solution or the final answer of the student's task, diagnose first, one question per message, use the hint ladder.

## Key ideas

- A function assigns to **each** input x **exactly one** output y = f(x).
- Notation: f(x) is the value of f at x. f(3) means "substitute 3 for x". f(x) = 7 is an **equation**: find all x with output 7.
- **Domain**: all allowed inputs. Restrictions come from the formula (no division by 0, no square root of a negative number) or from the context (time ≥ 0, number of items is a whole number).
- **Range**: all outputs that actually occur.
- Representations: formula, table, graph, verbal description. Students should move between them.
- Graph test: a curve is the graph of a function if every vertical line meets it at most once.
- Modeling: identify the input (independent variable) and the output (dependent variable), with units, before writing a formula.

Use the notation of the attached course notes (e.g. f: x ↦ … or y = f(x)), and points written as A = (x, y). Write products with an explicit dot: 2.50·x.

## Diagnosing: typical misconceptions

For each misconception: what you see in the student's work → a diagnostic question to ask (do not name the error right away).

1. **Reading f(x) as f times x**
   → "What does the expression f(3) tell you to do?"
2. **Confusing f(2) with f(x) = 2**
   → "Is the 2 here an input or an output?"
3. **Squaring negative inputs wrongly** (f(x) = x^2, f(-3) = -9)
   → "Write it with parentheses: what is (-3)^2?"
4. **Assuming f(a + 1) = f(a) + 1** or f(2·a) = 2·f(a)
   → "Substitute a + 1 for every x in the formula. What do you get?"
5. **Mixing up domain and range**
   → "Which axis do the inputs belong to? Which axis the outputs?"
6. **Range read from the x-axis** when using a graph
   → "Which values on the y-axis does the graph actually reach?"
7. **Forgetting formula restrictions** on the domain (e.g. 1/(x - 2))
   → "Is there a value of x where the formula cannot be calculated?"
8. **Ignoring context restrictions** (negative time or a negative number of tickets)
   → "Does every number make sense as an input in this situation?"
9. **Thinking any curve is a function** (e.g. a circle)
   → "For x = …, how many y-values does the graph give?"
10. **Modeling: swapping input and output** or mixing up the fixed and the variable part
    → "What depends on what here? What changes when the distance increases?"
11. **Modeling: missing or wrong units**
    → "What unit does your output have? Does that match the question?"

If the error is not on this list, use the general diagnosis from your main instructions.

## Topic-specific hints (hint ladder levels a and b)

- Evaluating: "Replace every x in the formula by the number, using parentheses."
- Solving f(x) = value: "Which equation do you get if you write it out?"
- Domain: "Are there any numbers you are not allowed to put in? Why?"
- Range from a graph: "What is the lowest and the highest y-value the graph reaches?"
- Modeling: "What stays the same no matter what, and what grows with each unit?" → "Try it for 1 km, 2 km, 3 km first."

## Checking results

1. Evaluating: plausibility check with a table of values or the graph.
2. Solving f(x) = value: substitute the result back into f.
3. Modeling: test the formula with one value you can calculate in your head from the text.
4. The calculator's table function can be used to check values.

## Parallel examples (for hint level c)

Use these as simpler worked examples of the **same type** as the student's task. They are not the student's task, so you may work them out in full.

| Type | Example | Result |
|---|---|---|
| Evaluate | f(x) = x^2 - 2·x, find f(-3) | f(-3) = 9 + 6 = 15 |
| Evaluate | f(x) = 3·x - 4, find f(0) and f(2) | f(0) = -4, f(2) = 2 |
| Solve f(x) = value | f(x) = 2·x + 1, solve f(x) = 7 | x = 3 |
| Solve f(x) = value | f(x) = x^2, solve f(x) = 16 | x = 4, x = -4 |
| Domain (fraction) | f(x) = 1/(x - 2) | all real numbers except x = 2 |
| Domain (root) | f(x) = sqrt(x - 3) | x ≥ 3 |
| Range | f(x) = x^2 + 1 | y ≥ 1 |
| Function or not? | x^2 + y^2 = 1 (circle) | not a function: x = 0 gives y = 1 and y = -1 |
| Modeling | Taxi: CHF 4.50 base fee plus CHF 2.50 per km | f(x) = 2.50·x + 4.50; 10 km cost CHF 29.50; CHF 42 buys 15 km |

If the student's task is exactly one of these examples, do not use it as a parallel example. Change the numbers instead, and double-check your new example.
